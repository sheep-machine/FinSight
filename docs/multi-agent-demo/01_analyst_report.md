## 关键发现

1. **"增收不增利"格局加剧**：剪刀差达30.8pct [置信度: 95%]
2. **毛利率逼近历史低位**：6.94%接近2022年5.92%低点 [置信度: 88%]
3. **经营性现金流大幅恶化**：下降34.5%，与EBITDA增长45.2%形成反差 [置信度: 85%]
4. **大客户依赖度极高**：海外收入占比69% [置信度: 82%]
5. **新能源汽车业务为结构性亮点**：收入205亿(+45.5%)，毛利率约20% [置信度: 72%]
6. **资产负债结构持续优化**：有息负债下降26% [置信度: 88%]
7. **AI新业务处于早期培育阶段** [置信度: 70%]
8. **Q4利润环比下滑22.2%** [置信度: 80%]
